mdaw 0.2.0 is a prototype build for Linux x86-64: the client (`mdaw`), the server (`mdaw-server`)
and the plugin scanner (`mdaw-plugin-scan`, which must stay in the same folder as `mdaw`).
Unpack it and run `mdaw-server --data ./mdaw-data --host <name>`, then
`mdaw --join '<join string>' --name <you>`.

## What is new

- **Tracktion Engine plays.** Each client plays the shared project on its own machine through
  Tracktion Engine. The built-in instrument (Pocket) is Tracktion's 4osc synth.
- **Plugins: VST3, LV2 and CLAP**, with their own windows. Anyone can put a plugin on any track;
  its settings travel with the project. A client without the plugin shows the track as "plugin
  not installed" and plays the rest.
- **Plugins are examined in a separate scanner process**, so a plugin that crashes or hangs while
  being examined is listed as failed and not offered. Once loaded, plugins run inside the
  client: a plugin that crashes takes the client down.
- **No edit is lost or applied twice.** The client keeps its unsent edits on disk and sends them
  again after a reconnect or a restart; the server keeps a receipt per edit and writes every
  edit to disk before anyone hears of it.

## Before you upgrade

- **Linux only.** There is no Windows build until the bridge to Tracktion is ported.
- **Projects of 0.1 are not readable.** A 0.2 server refuses a data directory of 0.1, and 0.1
  clients and servers cannot talk to 0.2 ones (protocol 11, store format 7). Start the server
  with a fresh data directory. Unsent edits saved by an earlier client are refused as well (0.1
  itself kept none on disk). The client's profile, its identity and name, carries over.
- **Licence.** The client (`mdaw`, `mdaw-plugin-scan`) links JUCE 8 and is distributed under the
  GNU AGPL v3 (`LICENSE-AGPL`); the server stays under the GNU GPL v3 (`LICENSE`).

## What went since 0.1

People now collaborate on the project, not on the audio clock (see `docs/migration-checklist.md`,
"Removed", for the dates):

- The shared transport and clock: each person plays and stops on their own, with their own
  playhead.
- Checkout and commit with changelog samples: every edit is an ordinary edit, on any track. The
  changelog lists edits displaced by someone else's, with Restore.
- Network MIDI: others hear notes played on your keyboard once you have recorded them into a
  clip. Playing your own instrument from the computer keyboard or a MIDI device, and recording,
  stay.
- The Rust audio engine and its synth: 0.1's Pocket synth is gone; the built-in instrument is the
  4osc one.

The client needs the ALSA, X11 (or Wayland), freetype and fontconfig libraries, which desktop
distributions have; JACK is used if it is there.
